## 👨‍💻 Sobre mim

Sou **Analista de QA / Testes de Software**, com foco em garantir
**qualidade, estabilidade e confiabilidade** em sistemas e produtos digitais.

Minha trajetória começou em **Suporte de TI**, experiência que me proporcionou
uma visão prática sobre o comportamento dos usuários e ambientes corporativos.
Hoje aplico essa perspectiva em Quality Assurance para identificar falhas,
antecipar problemas e contribuir para melhores experiências e entregas.

Atuo principalmente com:

- 🧪 Planejamento, criação e execução de testes
- 🌐 Testes de aplicações Web
- 🔌 Testes de APIs
- 📱 Testes Mobile
- 🤖 Automação de testes
- 📋 Análise e validação de requisitos
- 🐞 Investigação, documentação e acompanhamento de bugs
- 🔎 Análise de logs e troubleshooting
- 🗄️ Validação de dados utilizando SQL
- ☁️ Validação de sistemas SaaS
- 🧠 IA aplicada à Qualidade de Software
